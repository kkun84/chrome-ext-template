# Security Policy

## Supported versions

This repository is a starter template. Security fixes land on the default
branch. If you forked it, please rebase or cherry-pick updates from upstream.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting**:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include enough detail to reproduce the issue (affected files, steps, and
   impact). Do not include secrets you do not control.

Do **not** open a public issue or discussion for a vulnerability.

We will acknowledge the report and follow up on next steps. If you do not
receive an acknowledgement, you may send a reminder through the same private
channel.

## Project security defaults

The template is set up for a public repository. After you create or push the
repo, also complete the settings checklist in `README.md` (Dependabot alerts,
secret scanning and push protection, a branch ruleset for `main`, and
immutable releases when you publish GitHub Releases).
